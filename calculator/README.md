# Calculator Project - Jujutsu Workshop

A simple calculator application with both a Node.js backend and an HTML/CSS/JavaScript frontend.

## Features

- Basic arithmetic operations 
  - addition, subtraction, 
- Input validation and error handling
- Clean and responsive web interface
- Comprehensive test suite

## File Structure

- `calculator.js` - Core calculator functions
- `utils.js` - Utility functions for formatting and validation
- `test.js` - Test suite for all functions
- `index.html` - Calculator web interface
- `styles.css` - Styling for the calculator
- `app.js` - Frontend JavaScript logic

## Getting Started

### Running Tests

```bash
node test.js
```

### Using the Web Interface

Simply open `index.html` in your web browser.
